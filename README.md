# Система мультимодального анализа и поиска изображений по пользовательским запросам.

## Что делает?
- Создает мультимодальные эмбеддинги для изображений;
- Осуществляет поиск изображений по текстовому запросу с использованием векторной БД Qdrant;

## Архитектура:
1. Pytorch - для обработки изображений и создания эмбеддингов;
2. Qdrant - хранение эмбеддингов и осуществление поиска по ним;
3. FastAPI - api для обмена информацией между qdrant и веб-интерфейсом;
4. Streamlit - веб-интерфейс для удобства пользователей.

## Как запустить проект при помощи docker-compose.yml:
1. `docker compose up --build`

## Куда смотреть после запуска:
1. В начале зайти на: http://localhost:8000/docs
2. Затем в Streamlit: http://localhost:8501/
3. В Streamlit нажать на кнопку "Найти"
4. Qdrant: http://localhost:6333/dashboard#/collections
