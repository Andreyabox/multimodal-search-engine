# search-engine
# Система мультимодального анализа и поиска изображений по пользовательским запросам.

## Что делает?
- Создает мультимодальные эмбеддинги для изображений;
- Осуществляет поиск изображений по текстовому запросу с использованием векторной БД Qdrant;

## Архитектура:
1. Pytorch - для обработки изображений и создания эмбеддингов;
2. Qdrant - хранение эмбеддингов и осуществление поиска по ним;
3. FastAPI - api для обмена информацией между qdrant и веб-интерфейсом;
4. Streamlit - веб-интерфейс для удобства пользователей.

## Как запустить проект при помощи Dockerfile:
1. Создаем образ: `docker build -f api\Dockerfile . -t search`
2. Запускаем контейнер: `docker run -p 8000:8000 search`

## Куда смотреть после запуска:
1. Для просмотра приветствия "Welcome to the Multimodal Search Engine API!": http://127.0.0.1:8000/
2. Дальше, можно зайти на http://127.0.0.1:8000/docs и найти POST /search и раскрыть
3. Нажать "Try it out", затем кнопку Execute
4. После некоторого ожидания получим JSON ответ, где в "image_url" указана ссылка на 
наиболее соответствующее текстовому запросу изображение.
5. Текстовый запрос по дефолту отмечен как "string" его можно заменить на любой другой.
